# Interfaz Gráfica con Tkinter

Este proyecto utiliza el módulo `Tkinter` para desarrollar una interfaz gráfica que simula una calculadora básica. Este README detalla la funcionalidad del programa, las instrucciones para su uso y una demostración visual.

---

## Descripción

Esta calculadora gráfica permite realizar operaciones matemáticas simples como suma, resta, multiplicación y división. La interfaz está diseñada de forma intuitiva, con botones para cada número y operación que el usuario puede presionar para construir la expresión deseada y ver el resultado.

### Características
- **Operaciones soportadas**: suma, resta, multiplicación y división.
- **Funciones adicionales**: limpiar la pantalla y calcular el resultado.
- **Validación de errores**: muestra un mensaje en caso de que la operación sea inválida.

---

## Instrucciones de Uso

### Requisitos
Para ejecutar este programa, debes tener instalado **Python 3** y el módulo `tkinter` (incluido en la mayoría de instalaciones de Python por defecto).

### Ejecución

Para iniciar la calculadora, abre una terminal, navega hasta el directorio donde se encuentra el archivo `calculadora.py` y ejecuta el siguiente comando:

```
py calculadora.py
```
